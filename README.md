# MyWallet

כתובת האפליקציה: https://ronen1m.github.io/MyWallet/

אפליקציית ארנק פשוטה שמציגה כמה כסף יש בארנק, עם:

- יתרה במרכז המסך שמתעדכנת לפי תשואה שנתית (ריבית דריבית)
- שם האפליקציה (בהתקנה, בלשונית ובמסך הפתיחה) הוא תמיד "הארנק שלי"
- במסך הראשי לוחצים על הכותרת כדי לרשום את שם הילד, והכותרת הופכת ל"הארנק של X"
- כפתור הגדרות (גלגל שיניים) לשינוי התשואה השנתית, שמוצגת בפינה השמאלית העליונה
- כפתורי הוספת כסף והוצאת כסף, עם תיאור חובה (מאיפה קיבלת / על מה הוצאת)
- רשימת תנועות שאפשר לפתוח ולסגור
- שמירה וטעינה של קובץ גיבוי (‎.json)
- אפשר להתקין על מסך הבית של הטלפון, והאפליקציה עובדת גם בלי אינטרנט

## איפה הנתונים נשמרים

הנתונים נשמרים **רק בדפדפן של המכשיר** (localStorage). המשמעות:

- כל מכשיר וכל דפדפן מחזיקים נתונים נפרדים.
- מחיקת נתוני הגלישה או האתר תמחק גם את נתוני הארנק.
- בגלישה בסתר הנתונים לא נשמרים.

לכן כדאי לשמור מדי פעם קובץ גיבוי עם הכפתור "שמירה לקובץ". אותו קובץ אפשר גם לטעון במכשיר אחר.

## פרסום ב-GitHub Pages

1. מעלים את הקבצים לריפו ב-GitHub.
2. בריפו נכנסים ל-**Settings → Pages**.
3. תחת **Build and deployment** בוחרים **Deploy from a branch**, את הענף `main` ואת התיקייה `/ (root)`, ושומרים.
4. אחרי כמה דקות האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-הריפו>/`.

הערה: ב-GitHub Pages בחינם הריפו צריך להיות ציבורי. הקוד יהיה גלוי לכולם, אבל הנתונים של הארנק לא, כי הם נשמרים רק בטלפון.

## התקנה על הטלפון

- **אייפון (Safari):** פותחים את הכתובת, לוחצים על כפתור השיתוף ובוחרים "הוסף למסך הבית".
- **אנדרואיד (Chrome):** פותחים את הכתובת, לוחצים על שלוש הנקודות ובוחרים "התקן אפליקציה" או "הוסף למסך הבית".

## עדכון גרסה

אחרי שינוי באחד הקבצים, מעלים את מספר הגרסה ב-`sw.js` (למשל `ofir-wallet-v3` ל-`ofir-wallet-v4`), כדי שהטלפונים יקבלו את הגרסה החדשה.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה (עיצוב וקוד) |
| `manifest.webmanifest` | הגדרות ההתקנה על מסך הבית |
| `sw.js` | שמירת הקבצים לעבודה בלי אינטרנט |
| `icon.svg`, `icon-*.png`, `apple-touch-icon.png` | האייקונים |
